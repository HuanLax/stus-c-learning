COS10009 Introduction to Programming：C / raylib 俯视角单机探险项目。

**第八阶段进行中：已接入第一批主城、建筑、人物、NPC、哥布林和 Boss PNG；存读档与完整主线保留。**
先向主城村长接取“灰溪村的求援”，清剿四只近战和两只远程哥布林，回村交付后进入巢穴；击败格鲁克再向村长报告。
已接入三张地图底图、人物、NPC、治疗石、传送阵、洞穴障碍及四种武器图标；攻击效果仍为占位。镜头为 2 倍，数值和美术仍需试玩调整。主城建筑、矮墙、花坛保留显示但可穿过，NPC 挡路；野外移除独立城墙、树木和石头，底图装饰可走。所有治疗石都有脚底碰撞，地图外围与洞穴边界仍保留。

## 运行

在 VS Code 中打开本目录：

窗口支持拖动边缘缩放和最大化，最小 640×480。游戏先绘制到 1024×768 虚拟画布，再按比例适配窗口；其他宽高比留边，鼠标坐标同步换算，UI 和地图镜头不因窗口尺寸错位。

1. `Ctrl+Shift+B` 构建 Debug。
2. `F5` 使用已配置的 GDB 调试启动。

3. 点击“新游戏”（N）或“继续游戏”（C）；有合法存档时 Enter 默认继续，否则开始新游戏。有已有文件时，新游戏需确认。WASD / 方向键移动。
4. 靠近 NPC、治疗点或入口，按 E 或点击交互按钮。主城右侧入口进入野外，野外左侧入口返回主城；右侧巢穴入口在清剿任务交付后解锁。
5. J / 鼠标左键普攻，按住按冷却连续攻击；Q 切剑/法杖。金色短线为剑四向，蓝色长线为法杖八向；鼠标不控制朝向。主城和入口安全区禁止攻击。
6. 橙色矩形为近战预警，橙色线为远程射击方向；及时移动躲避。死亡后用左右键 + Enter 或鼠标选择主城/当前地图安全区，满血返回。
7. 安全区内按 E 或点击治疗点恢复满血；Esc 暂停/返回，F2 切换语言。关闭界面后松开 J 和鼠标，再按下才攻击。
8. 游戏窗口内按 F5，和平且存活时保存；战斗中禁止手动保存。在菜单点击退出或使用窗口 X 会自动保存现场，战斗中也保留原地图、位置、怪物、飞行攻击与冷却。继续游戏恢复退出时的界面；暂停退出后仍暂停。保存失败时可重试、取消退出或明确选择不保存退出。
9. B 打开背包，方向键或鼠标选格，Enter 或“装备”手动穿戴；战斗中可以查看但不能换装。B / Esc 关闭。
10. 主城靠近商人按 E 或点击打开商店；选商品再按 Enter / 点击“购买”。钢剑 75、符文法杖 100，各限购一次，购买不自动装备。
11. 每只哥布林奖励 25 金币与 30 经验；升级只恢复增加的生命值部分。角色、金币、装备和任务在切图/死亡复活后保留，成功存档后也可在重启时恢复。
12. 村长对话用 Enter / 鼠标翻页，在最后一页接受或交付；Esc 可暂时离开。接取前的击杀不计入任务，接取后的进度在死亡、切图后保留。
13. 哥布林王的橙色扇形是重斩预警，三条橙线是散射预警；预警时方向锁定，可以绕侧面或避开射线。击败后回村长处完成最后交付，通关后可以继续探索。

日常试玩也可使用 `Ctrl+Shift+P` → `Tasks: Run Task` → `Run game (no debugger)`，该任务先构建，再直接启动游戏，不经过 GDB。
F5 用于断点学习：如果 VS Code 显示暂停或黄色执行箭头，游戏也会暂停处理输入和关闭事件；继续执行用 F5，停止调试用 Shift+F5。

PowerShell 也可以运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -Configuration Debug
& .\bin\project-lax.exe
```

Release：将 `Debug` 改为 `Release`。两种配置输出同一个可执行文件；F5 会先重新构建 Debug。
脚本的执行策略选项只作用于该次进程，没有修改系统策略。

检查移动和碰撞：在构建命令后增加 `-CheckMovement`。测试源文件在 tests，生成的测试程序在 bin，不混入游戏的 main。
检查战斗：增加 `-CheckCombat`，两项可以同时使用。
检查怪物行为：增加 `-CheckAI`；三项可以同时使用。
检查背包成长：增加 `-CheckInventory`，可以同时启用四项。
检查主线与 Boss：增加 `-CheckQuest`，可以同时启用五项。
检查存读档：增加 `-CheckSave`，可以同时启用六项。检查使用 bin 内独立测试文件，不修改实际游戏存档。
任意怪物发现玩家后 HUD 显示战斗中；所有怪物都无法探查连续五秒后和平并返回，重新发现会清零倒计时。进入安全区立即脱战，存活怪物返回原位，不回血、不复活。

直接预览巢穴与 Boss：`& .\bin\project-lax.exe --preview-boss`。这是绕过入口的开发预览，不替代正常接取与交付流程，禁用手动与退出存档。`--smoke-test` 同样不写实际存档，只导出当前阶段截图。

## 存档

一槽文本文件：`saves/save.txt`，首次成功保存时自动创建目录。路径按可执行文件所在 bin 目录定位，切换终端工作目录仍使用同一个存档。
保存地图与 XY、生命、等级与经验、金币、12 格背包、装备下标、购买记录、当前武器、分类击杀计数、任务阶段、Boss 状态、语言和最近安全区。
版本 2 还保存当前地图怪物的存亡、生命、位置、巡逻/追击/返回状态、攻击预警、投射物、冷却、剑已命中标记，以及背包/商店选择、对话页码和当前界面。离线期间不推进计时。生命上限、基础攻击和移速按当前规则重建。
死亡菜单退出保存零生命和复活选项，继续后仍需选择复活。切图或完成复活刷新怪物，包括已击败的 Boss。Boss 每次刷新后的击杀可领取一次掉落，主线交付奖励仍只领取一次；读档保持当前 Boss 存亡状态，不立即刷新。
兼容版本 1：恢复已有进度并重建怪物；旧坐标恰好位于新增治疗石碰撞内时迁到旁边合法安全位置。最近安全点字段保留兼容用途，不再用于战斗退出传送。
坏存档不会应用或自动覆盖；确认新游戏后，下一次成功保存或正常退出才替换它。主菜单直接退出不会覆盖已有文件。
先写 `save.txt.tmp`，完成后替换正式文件，失败保留旧存档。强制结束程序只保证上一次成功保存的进度。
复制项目到新目录时，若希望保留进度，也复制 saves 目录；个人存档已加入 `.gitignore`。

## 已检查的工具路径

- 编译器：`C:\raylib\w64devkit\bin\gcc.exe`，GCC 15.2.0，64 位 MinGW-w64。
- 调试器：`C:\raylib\w64devkit\bin\gdb.exe`。
- raylib 6.0：`C:\raylib\raylib\src` 内的 `raylib.h` 与 `libraylib.a`。
- 使用 C99、UTF-8、`-Wall -Wextra -Wpedantic -Werror`。
- 每个 `.c` 独立编译，由 GCC 链接为 `bin/project-lax.exe`；`main.c` 不包含其他 `.c`。
- 路径变化时修改 `scripts/build.ps1` 参数及 `.vscode` 配置，不依赖终端里恰好找到哪一套 GCC。

## 中文字体

资源加载优先查找 `assets/fonts/NotoSansCJKsc-Regular.otf`，路径相对于可执行文件定位，不依赖终端工作目录。
项目已附带 Noto Sans CJK SC 简体字体，以及 `assets/fonts/LICENSE.txt` 中的 SIL Open Font License 1.1。
正常运行使用项目字体，不依赖 Windows 黑体。提交时请一起保留字体和授权文件。
仅在项目字体缺失时尝试已安装的 `C:/Windows/Fonts/simhei.ttf`，并显示“开发字体”提示；两种字体均不可用时回退英文，中文按钮禁用。
字体加载后会逐一检查所需字形，不把缺字方框误认为中文显示成功。
