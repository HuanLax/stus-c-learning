## 目标与课程要求

使用 C99 / raylib，完成可通关、支持中英文的俯视角单机探险游戏；用户需要能在面谈中解释关键实现。
不使用 goto 或全局变量。用数组、struct、enum、函数分工和参数传递表达数据与逻辑。
不使用第三方游戏模板中现成的全局游戏状态。

依据用户提供的《COS10009 Portfolio Format and Assessment Criteria》，Semester 2, 2026：

- 第 5 页 Pass：数据处理逻辑、数组、原创实现、可运行、友好交互、函数分工与参数传递；目标与结构图/流程图。
- 第 6 页 Credit / Distinction：数组与记录、自定义类型、命名、注释、缩进、功能说明与数据字典。
- 第 7 页 HD：额外高级功能、有用抽象、合理组织、解释设计理由的注释和设计报告。
- 可靠存读档作为本项目 HD 重点，但 PDF 没有规定存档自动等于 HD。
- Portfolio 还包含测试、每周任务、Learning Summary Report、反思视频与面谈；本游戏不替代这些项目。

## 地图、坐标与美术

| 地图 | 暂定尺寸 | 安全规则 |
|---|---|---|
| 主城 | 已确定 30×30 格 | 全图安全，固定出生/复活点 |
| 野外 | 暂定 40×40 格 | 入口 3×3 格安全区 |
| 巢穴 | 暂定 24×24 格 | 入口 3×3 格安全区 |

每格暂定 32 像素。地图地形用二维数组，玩家/怪物用浮点 XY 坐标连续移动。
原点在地图左上，X 向右、Y 向下；世界坐标与屏幕坐标分离。
镜头跟随玩家并限制在地图边界；较小地图需要居中，不能使用负的镜头限制范围。HUD 固定。

玩家和普通怪物显示约一格，身体碰撞框略小；Boss 暂定 2×2 格。
八向移动速度归一化，禁止从封闭墙角斜穿。碰撞分 X/Y 轴处理。
移速候选为每秒 2–3 格，试玩确定；并非已经锁定具体数值。

美术统一像素风：地面、场景对象、角色三类资源；场景与角色按脚底 Y 排序。
贴图与碰撞数据分离，保留资源替换入口。主城建筑只作外观和障碍，不进入室内，NPC 全在主城室外。
主要设施集中，外围可预留新 NPC 位置。替换地图布局时需要同步障碍、出口及出生点数据。

## 输入与界面

| 操作 | 输入 |
|---|---|
| 移动 | WASD / 方向键 |
| 攻击 | J / 鼠标左键，按住按冷却连续普攻 |
| 切换武器 | Q |
| 交互 | E / 显示的交互按钮 |
| 背包 | B |
| 手动存档 | F5，仅和平状态 |
| 暂停/关闭当前界面 | Esc |
| 界面选择/确认 | 方向键与 Enter / 鼠标 |

鼠标不改变朝向。界面打开暂停世界更新，但不把战斗状态变成和平。
界面消费输入，关闭界面后必须松开鼠标再攻击。J 和鼠标共用冷却。
交易、装备等采用按下触发一次。按钮显示悬停、选中和不可用状态。
游戏内语言通过菜单切换；阶段 1 临时使用 F2 验证。F5 留给存档，不与游戏内 F2 冲突；VS Code 的 F5 是调试快捷键。

## 战斗与怪物

- 剑四向：前方矩形攻击区域，范围由参数表确定；可以命中多个怪物，同一次挥击对每个目标只伤害一次。
- 法杖八向：直线投射物，当前射程八格（256 像素），与普通远程哥布林一致；碰墙或第一个敌人消失。斜向射程按实际距离计算。2026-10-15 依据试玩反馈由三格延长，速度仍为 240 像素/秒。
- 位置与命中由碰撞框判断，不要求目标对齐某格。攻击不能隔墙命中，身体接触不直接扣血。
- 剑四向由移动方向确定：斜向时优先保留此前相符朝向，否则优先纵向；画面明确显示。
- 攻击中可移动，剑方向锁定，攻击区域随身体移动；切武器不能重置共用冷却。
- 普通怪物在出生点附近固定点巡逻；发现需要探查距离与无遮挡。
- 发现后允许当前全图追击，无出生点距离限制；不能跨地图或进入安全区。
- 怪物八向移动，通过网格 BFS 绕障碍；禁止夹角斜穿，不每帧重新寻路。怪物之间先不做实体碰撞。
- 近战怪物靠近后预警、锁定方向、挥击、冷却。
- 远程怪物尝试保持距离，无遮挡时预警并发射直线投射物；无路后退就原地应战。
- Boss 初版重斩与三发散射，均有预警、方向锁定及恢复时间；无接触伤害，不加入额外阶段。
- 玩家受伤后短暂无敌并闪烁；具体时间与所有伤害、范围、速度待试玩调整。

## 安全区、死亡与刷新

没有任何怪物能探查玩家连续 5 秒后脱战；期间怪物追向最后看到的位置，重新发现会清零计时。
玩家完整进入安全区立即脱战，取消敌方攻击并清除敌方投射物。
安全区内玩家不能攻击外面怪物；治疗需要交互，不在跨过边界时自动回满。
怪物返回原位途中不攻击、不重新追击；到位后巡逻。进入安全区不恢复其生命、不复活死怪。

死亡暂停，选择主城或当前地图固定安全区，满血复活；不扣金币经验装备。
切图、死亡复活重建怪物，包括 Boss；主线击败记录与当前 Boss 存亡分开，重复击杀有正常掉落，主线奖励不重复。版本 2 读档恢复当前地图现场；旧版读档因无现场数据才重建。
主城安全出生点和各地图入口安全区均为有效安全点，进入后更新最近安全点记录。

## 成长、任务和背包

- 玩家最高 5 级；升级增加最大生命和基础攻击，当前生命恢复新增部分。
- 主线“灰溪村的求援”：村长艾德委托 → 接取后累计击败 4 只近战、2 只远程哥布林 → 回城交付（50 金币、60 经验）并解锁巢穴 → 击败哥布林王格鲁克（150 金币、120 经验） → 回城交付（100 金币、60 经验）并显示通关。
- 普通怪物刷新后的击杀允许累计；每次击杀奖励一次，任务及 Boss 奖励只领取一次。
- 背包 12 格，第一版只装武器；金币单独记录，不加材料和药水。
- 开局普通剑与法杖已装备；剑槽与法杖槽各一个。
- 已装备武器仍占背包格，装备槽引用对应格子；更换后旧武器保留。
- 商人售升级剑/法杖，各限购一次；购买入背包不自动装备。
- 金币不足或背包满不扣款；和平才能换装，战斗可查看背包。
- 攻击力由角色基础值与当前装备加成计算，不反复把装备加成累加到基础值。
- 可交互资源先采用治疗点。通关后允许继续探索。

## 存档方案

一槽、带格式版本的文本存档。保存地图/XY、生命、等级/经验、金币、背包、装备引用、购买状态、当前武器、任务、Boss 状态、语言和最近安全区。

和平且存活时可 F5 手动保存；和平/战斗正常退出都保存实际位置与现场，继续后不计算离线时间。
死亡菜单直接退出保存零生命、死亡界面与复活选择，继续后由玩家确认复活。背包、商店、对话、暂停界面及选项也恢复。
窗口关闭与菜单退出走同一保存逻辑；强制结束只保证上一次成功存档。

读入临时记录，检查字段完整性、版本、数值范围、有限坐标、可站立位置、等级/生命、经验、装备引用与任务关系，以及怪物类型/数量/状态、攻击和界面关系，合法才应用。
保存当前地图怪物、导航目标与路径计时、投射物、预警、冷却、命中记录、朝向和受伤闪烁计时；不存内存地址、贴图或 GPU 资源。世界静态配置与战斗规则由程序重建。
先写临时文件，检查完成后替换正式文件；失败保留旧存档并提示。坏存档不自动覆盖，新游戏覆盖需确认。
