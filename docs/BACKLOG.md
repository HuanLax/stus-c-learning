## 目标

让剑与法杖不只是两把武器，而是两种资源循环：

- 剑：近战、攒斗气、稳定
- 法杖：远程、花斗气、爆发
- 大招：斗气满时的清场/保命手段
- Boss：血量过半后多一个阶段，演示时有变化

## 一、斗气系统

### 数据

`Player` 增加：

```c
int qi;
int maxQi;
```

首版固定：

```c
maxQi = 100;
qi = 0;          /* 新游戏 */
```

### 获取与消耗

| 事件 | 变化 |
|---|---|
| 剑命中一次 | +12 |
| 玩家受击一次 | +8 |
| 击杀一只普通怪 | +15 |
| 击杀 Boss | +40 |
| 法杖发射一次 | -20 |
| 大招 | -100 |

规则：

- `qi` 限制在 `0..maxQi`
- 斗气不够时，法杖不发射，不进入冷却
- 斗气不够时，大招不触发，不进入冷却
- 不在战斗外自动回复；斗气只能靠战斗行为获得
- 切图、死亡复活保留当前斗气

### 设计理由

剑命中回斗气，法杖消耗斗气，玩家会自然地在两种武器之间切换。受击也回一点斗气，避免被压着打时完全没有反击资源。

## 二、大招：斗气爆发

### 输入

`R` 键。

### 条件

- `qi >= 100`
- 玩家存活
- 不在界面/对话/死亡状态

### 效果

- 以玩家为中心，半径 140 像素的 360° 斩击
- 伤害 = 当前攻击 × 3
- 命中所有范围内敌人，每个敌人只结算一次
- 施放期间 0.8 秒无敌
- 消耗全部斗气
- 不另设冷却；斗气就是冷却

### 表现

首版不做复杂动画：

- 白色/金色圆环快速扩张
- 屏幕轻微震动 0.15 秒
- 命中敌人闪白
- 斗气条清空

### HUD

- 斗气条：琥珀色，放在 HP 条下方或经验条右侧
- 满 100 时：条尾端闪烁，显示 `R 就绪`
- 不足时：显示 `R 斗气不足`

## 三、Boss 二阶段

### 触发

Boss 血量首次降到 50% 以下时，进入第二阶段。

只触发一次，不回到第一阶段。

### 新增招式：地面砸击

- 预警：Boss 脚下出现橙色圆形预警，持续 1.2 秒
- 范围：半径 90 像素
- 伤害：18
- 冷却：6 秒
- 只在第二阶段使用
- 原有重斩、散射保留，交替使用

### 约束

- 预警期间 Boss 不移动
- 预警结束后才结算伤害
- 玩家在预警结束前离开圆形范围即可躲开
- 不增加接触伤害
- 不改变 Boss 血量、奖励和任务阶段

### 设计理由

只加一个招式，就能让演示里“Boss 有阶段变化”，又不用重写 Boss AI、任务和存档。

## 八、风险

1. **斗气不够时法杖完全不能用**：玩家可能觉得被剥夺了武器。需要试玩确认，必要时把法杖消耗降到 15。
2. **大招太强**：3 倍攻击 + 无敌可能直接跳过 Boss 阶段。试玩时优先削伤害，不要削无敌。
3. **Boss 二阶段太难**：砸击和散射同时出现会叠加。首版让砸击独立冷却，不和散射同一帧触发。
4. **存档版本迁移**：旧档读入失败会直接损失进度。必须先用副本测试，再动真实存档。
5. **范围扩大**：一旦开始加招式，很容易继续加。演示前只做本备忘录列出的内容。
