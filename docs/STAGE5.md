# 第五阶段：成长、背包和交易（2026-10-14）

## 实际完成

击杀金币/经验、最高 5 级、升级属性、12 格武器背包、剑/法杖装备槽、手动装备、商店、双语反馈与 HUD。
购买不会自动穿戴，旧武器保留；战斗中只能查看背包，暂停世界不解除战斗。
没有任务、Boss 战斗或存档；重新启动仍是新进度，不将内存保留误称为存档。

## 新文件为什么存在

- `inventory.h / inventory.c`：物品定义、背包数组、装备引用和不产生半笔交易的购买/装备逻辑。
- `tests/test_inventory.c`：检查失败交易、重复购买、升级上限、死亡保留等实际行为。
- 本文：阶段说明，不参与编译。
- player 增加成长；combat 发放一次奖励；ui 提供背包/商店；app 连接输入与这些模块。
- main 中旧阶段截图场景已简化为本阶段预览，正常游戏循环仍是更新→绘制。

## 先读哪些函数

1. inventory.h：ItemId、Inventory、ItemDefinition，理解“存的是物品 ID，而不是图片”。
2. InitializeInventory：初始格 0 铁剑、格 1 木法杖，两者开局装备；其余空。
3. BuyInventoryItem：检查限购→空格→金币→全部通过后提交。失败不扣金币，不设置购买标记。
4. EquipInventoryItem：战斗检查→下标/物品检查→仅修改对应装备槽下标。
5. GetPlayerAttack：基础攻击加当前装备加成；不修改基础值，反复换装不会累积属性。
6. ClaimEnemyRewards：检查 health 和 rewardGranted，每个怪物实例只领取一次。
7. GrantPlayerRewards：用 while 处理跨多个等级，最高 5 级；死亡时升级不能复活。

## 数据字典

| 数据 | 含义 |
|---|---|
| ItemId | 空格、铁剑、木法杖、钢剑、符文法杖 |
| ItemDefinition | 武器类别、攻击加成、售价、双语名称 ID；局部定义表 |
| Inventory.slots[12] | 物品 ID 数组，无堆叠、药水、材料、出售或丢弃 |
| equippedSword / equippedStaff | 已装备物品所在的背包下标，不另复制一件物品 |
| purchasedSword / purchasedStaff | 两种升级武器各限购一次的记录 |
| Player.level / experience | 当前等级、当前等级内经验；5 级经验清零 |
| Player.gold / baseAttack | 金币与角色基础攻击 |
| Player.defeatedGoblins | 累计击败普通怪物数，后续任务可以记录接取时基数 |
| Enemy.rewardGranted | 此次地图加载中的怪物奖励是否已发，避免逐帧重复奖励 |
| App.selectedSlot / selectedProduct | 界面选择，不属于永久角色数据 |
| App.inventoryMessage | 反馈文字 ID：成功、金币不足、背包满、战斗中等 |
| Combat.swingDamage / Projectile.damage | 攻击开始时确定的伤害，不随中途切武器改变 |

以上状态均在局部 App/Player/Combat 内，通过参数传递，不使用全局变量。

## 候选数值

| 项目 | 当前值 |
|---|---|
| 普通怪物奖励 | 25 金币、30 经验，在 combat.h 的 enum 常量定义 |
| 升级所需经验 | 1→2：60；2→3：100；3→4：140；4→5：180 |
| 每次升级 | 最大生命 +20、基础攻击 +4；当前生命只增加 20 |
| 初始生命/基础攻击 | 100 / 20 |
| 铁剑/木法杖 | 初始物品，额外攻击 +0 |
| 钢剑 | 75 金币，攻击 +12 |
| 符文法杖 | 100 金币，攻击 +12 |

例如初始角色用钢剑攻击为 20+12=32；升到 3 级基础值为 28，用钢剑为 40。
背包右侧“使用此武器攻击”是该物品穿戴并使用后的伤害；HUD 显示当前实际装备武器伤害。
清完六只怪物得到 150 金币与 180 经验，升到 3 级余 20 经验。切图重建后还能继续练级，角色奖励保留。
5 级后金币继续获得，经验不再积累，HUD 显示满级；奖励横幅仍显示怪物奖励规格。

## 为什么购买与装备分开

购买只把 ItemId 放入一个空格并扣款，不修改 equippedSword / equippedStaff。
玩家选中该格并装备后，对应槽引用它；旧物品仍在原格，已装备物品也占格。
Q 只切换当前使用剑/法杖，不替换槽内装备，也不清除攻击冷却。
伤害来自基础攻击与物品定义，每次查询重新计算，避免“脱下装备时扣错属性”。

## 为什么奖励不会重复

生命归零的敌人，第一次 ClaimEnemyRewards 标记 rewardGranted=true，再发奖励。
下帧仍能看到尸体记录，但不会再发。地图重建产生新怪物实例，可再次获奖。
奖励在死亡选择前结算；若玩家同帧死亡，升级只增加最大生命，当前生命保持 0，仍进入死亡界面。
死亡返回只恢复生命并重建临时战斗，不重新初始化 Player，所以等级、金币、背包和装备保留。

## 亲自验收

1. 新游戏按 B，确认 12 格、初始剑/法杖已装备、其余为空。方向键/鼠标选格，B/Esc 或关闭按钮返回。
2. 野外击杀一只：只得到一次 25 金币、30 经验。等待几秒不能继续涨钱。
3. 击杀第二只达到 2 级，最大生命 120、基础攻击 24；受伤时升级只恢复新增的 20 点。
4. 主城紫衣商人按 E/点击打开交易；金币不足时购买无效并提示，金币不变。
5. 凑够 75 买钢剑：金币扣除、商品售罄、背包多一件，但 HUD 仍是旧剑。
6. 关闭商店，B 打开背包，选钢剑点击装备/Enter；HUD 攻击变化，旧剑保留。
7. 买符文法杖并装备；Q 切换，确认两个槽各自使用所装备物品。
8. 战斗中 B 查看，世界暂停但仍战斗；装备按钮不可用。返回安全区后才能更换。
9. 重复购买不能扣款；空格不能装备；更换回旧武器不会永久加减基础值。
10. 死亡选择两种返回，等级/经验/金币/购买状态/装备保留，生命恢复新的上限。
11. 继续练到 5 级，不能升到 6 级；中英文界面和成功/失败提示均完整。

背包满在第一版正常物品种类中暂时不容易达到，自动测试使用满格数据验证失败不扣款。
