## 本次为什么新增文件

只新增两组游戏模块，避免把输入、移动和整个地图都塞进 main：

| 文件 | 原因与作用 |
|---|---|
| `world.h / world.c` | 地形数组、建筑和交互对象记录、碰撞、镜头、占位场景绘制 |
| `player.h / player.c` | 玩家位置/速度/朝向、脚底碰撞框、连续移动 |
| `tests/test_movement.c` | 独立检查移动速度、穿墙和镜头等容易出错的行为；不加入游戏源码构建 |
| 本文 | 本阶段的讲解与课程报告素材，不参与编译 |

已有 app、ui、text、main 随新功能更新。脚本自动收集 src/*.c；无需在 main 中 include 新 .c。
没有建立外部语言包文件夹：文字仍通过 text.c 的双语数组集中提供。

## 数据字典

| 数据 | 含义与单位 |
|---|---|
| `World.tiles[row][col]` | 二维地形；索引先 Y 行、后 X 列；草地/道路可走，墙阻挡 |
| `World.columns / rows` | 当前地图实际尺寸，数组容量为 40×40，实际尺寸可以较小 |
| `World.scenery[]` | 建筑/树/岩石记录；图片外观与 collision 分开 |
| `World.interactions[]` | NPC/治疗点/出口类型及脚底世界坐标 |
| `Interaction.destination / arrival` | 出口目标地图与到达坐标 |
| `World.spawn` | 地图固定出生/安全点；主城为 (480,528)，野外 (112,656)，巢穴 (112,400) |
| `World.safeArea` | 主城全图；野外/巢穴入口 96×96 像素矩形 |
| `App.worlds[] / currentMap` | 三张地图记录与当前 MapId |
| `App.lastSafeMap / lastSafePosition` | 最近进入的安全点，之后用于死亡与战斗退出 |
| `App.bossUnlocked` | 巢穴解锁标记，目前正常游戏为 false，之后由任务更新 |
| `Player.position` | 脚底中心世界坐标，浮点像素，不是数组下标 |
| `Player.speed` | 每秒像素；当前候选 96，即每秒 3 格 |
| `Player.swordFacing` | 单位四向向量，例如右 (1,0) |
| `Player.staffFacing` | 单位八向向量；斜向分量约为 ±0.707 |
| `App.screen` | 主菜单/探索/暂停/交互面板，有限状态 |
| `App.nearbyInteraction` | 最近可交互对象下标；-1 表示没有 |
| `App.camera` | 将世界坐标转换成屏幕坐标的 raylib Camera2D |

类型定义和 enum 常量不是全局变量。地图、玩家和镜头都放在 main 的局部 App 中，经参数传递。

## 你应先读哪几段代码

1. `world.c / InitializeWorld`：按 MapId 初始化；主城调用内部 InitializeTown。改布局先改这两处。
2. `player.c / MovePlayer`：输入方向→归一化→速度乘时间→分步碰撞。它不读取键盘，所以可以独立验证。
3. `app.c / UpdateApp`：实际读键盘，将方向与时间传给 MovePlayer；面板打开时不更新位置。
4. `world.c / GetWorldCamera`：根据当前地图尺寸限制镜头；DrawWorld 负责地面和按 Y 排序的对象。
5. `app.c / ActivateNearbyInteraction`：普通对象显示预览；出口通过 TryMapExit 检查后调用 EnterMap。

### XY 和格子怎样对应

地图宽高是 30×32=960 像素。像素位置 (100,70) 落在第 3 列、第 2 行（从零计数）。
角色不必停在格子中心。碰撞时检查整个脚底矩形覆盖的格子，而不是仅看角色中心。
窗口上方 128 像素为 HUD，地图绘制限制在下方区域；镜头坐标不混入碰撞逻辑。

### 为什么斜向不会加速

输入 (1,1) 的长度是 √2，归一化后约为 (0.707,0.707)。
位移=单位方向×每秒速度×经过秒数，所以直向和斜向的总路程相同。
前后台切换或调试产生长帧时，UpdateApp 将参与移动的时间限制为 0.05 秒，避免突然跳很远。

### 为什么分 X / Y 移动

先尝试 X，再尝试 Y；哪个方向撞墙就拒绝哪个方向，让另一个方向仍能移动。
每次检查位移不超过 4 像素，避免长帧跨过障碍。脚底框也阻止从封闭墙角斜穿。
建筑占地、边界墙和 NPC 身体都阻挡移动，治疗点/出口是可接近的交互标记。

### 不同尺寸的地图怎样处理镜头

世界宽 960，小于视口宽 1024，所以横向居中；世界高 960，大于地图视口高 640，所以纵向跟随。
镜头 Y 中心限制在 320 到 640 之间，靠近上/下边界就停止。
世界小于视口的情况单独处理，防止得到负的限制范围。
野外宽高都超过视口，可横纵跟随；巢穴宽 768，小于视口，横向居中。所有地图仍使用同一个 Camera2D 计算函数。

### 入口与安全区怎样工作

玩家需要按 E 或点击，不是踩到入口自动切图。TryMapExit 先检查出口下标、目标 MapId、Boss 锁定和到达位置碰撞，合法才返回目标。
EnterMap 更新地图和位置，清除旧交互下标，并重新计算镜头。UpdateApp 检查地图是否刚改变，该帧不继续旧地图移动。
失败时不改变地图和位置，显示锁定/错误提示；按住 E 不会反复切图。
安全区判断使用整个脚底碰撞框；只有完整进入才显示安全并更新最近安全点。记录固定安全出生点，不记录边界上不稳定的位置。

### 为什么前后遮挡成立

先画地面，再建立建筑、NPC和玩家的绘制列表，按脚底 Y 做插入排序。
靠下的对象后画，从而盖住靠上的对象。排序只重排绘制引用，不改变地图对象下标。
屋顶和树冠暂用透明度提示遮挡，脚底白圈和朝向线保持可见；最终贴图需要分离屋顶/树冠层。

## 亲自验收

1. Ctrl+Shift+B，然后 F5；点击进入主城或按 Enter。
2. 蓝衣玩家出生在中央道路；WASD 和方向键均可移动，静止保留朝向。
3. 比较直向/斜向速度；金色短线是剑四向，蓝色长线是法杖八向，目前不攻击。
4. 尝试走入建筑、石头、树干和 NPC；应被挡住。沿建筑边缘斜走应能滑动。
5. 走到上、下地图边缘：镜头停止，角色仍能在合法区域移动；左右各有居中留白。HUD 不随地图滚动。
6. 从屋顶、树冠后方与前方经过，观察遮挡排序；这是占位效果，不是最终美术。
7. 接近任务 NPC、商人、治疗点和出口：只出现最近对象的提示；离开后提示消失。
8. E 或点击交互按钮打开说明；按 Esc/E/Enter 或点击关闭。打开时移动停止，关闭点击不会触发其他操作。
9. Esc 暂停，移动停止；Enter/Esc 或继续按钮恢复。F2 切换后 HUD、名称与面板一起翻译。
10. 不应能接任务、买装备或回血；这些对象目前只是说明入口。
11. 到主城右侧“野外入口”，按 E 或点击：进入野外的绿色 3×3 区域。移出后 HUD 改为安全区外，完整进入后恢复安全。
12. 接近野外左侧“返回主城”，交互后回主城入口附近；按住 E 不应来回切换。
13. 沿野外中央道路向右，接近巢穴入口：应提示主线锁定，不能进入。
14. 单独运行 `& .\bin\project-lax.exe --preview-boss`，检查巢穴安全区、碰撞、镜头及返回野外。退出此预览再正常启动，任务状态不会改变。
