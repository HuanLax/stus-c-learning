## 故事与流程

灰溪村的庄稼和商路受到哥布林侵扰。村民冒险侦察，发现道路附近有四名持刀守卫和两名投石手，东边巢穴的头目格鲁克正在集结它们。村长艾德请求冒险者先夺回商路，再铲除头目。

| 状态 | 玩家行动与结果 |
|---|---|
| OFFER | 阅读村长三页对话，最后接受委托 |
| CLEAR_FIELD | 接取后累计击败 4 只近战与 2 只远程哥布林；HUD 显示各自进度 |
| REPORT_FIELD | 回村阅读两页报告并交付，获得 50 金币、60 经验，解锁巢穴 |
| HUNT_BOSS | 准备装备与治疗，进入巢穴击败格鲁克；获得 150 金币、120 经验 |
| REPORT_BOSS | 回村最后交付，获得 100 金币、60 经验 |
| COMPLETE | 显示通关，可以继续探索；头目不会再刷新，村长不会重复发奖 |

这是一次短主线的完整起因、调查、清剿、升级威胁和结局，没有增加支线、材料或额外地图。
普通怪物的 25 金币、30 经验奖励与任务交付奖励分别结算。
任务统计按类型累计，不要求六个固定怪物编号；死亡或切图后可以继续累计。

## 新文件为什么存在

- `src/quest.h / quest.c`：任务状态、计数、解锁判断、对话选择和一次性奖励。
- `src/boss.h / boss.c`：头目重斩与散射逻辑、命中判定和攻击预警。
- `tests/test_quest.c`：验证任务流程、奖励、实际 Boss 战斗与死亡边界情况；不参与正常游戏运行。
- 本文：学习和验收记录，不参与编译。

对话文字继续放在现有 `text.c` 的双语表中，不另建一个只有几句文本的语言文件夹。当前 `TextId` 对应固定中英文文本；以后若改为外部语言文件，需要再加入文件读取与错误处理。
`app.c` 连接任务、地图和界面；`ui.c` 绘制对话和处理按钮；`enemy_ai.c` 复用追击、返回和寻路；`combat.c` 处理伤害与奖励。
所有新增状态仍由局部 `App` 持有，通过参数传递。

## 先读哪些代码

1. `quest.h`：六个状态和 `Quest` 记录。一个 enum 表达当前阶段，避免“已接取、可交付、已完成”等多个布尔量出现互相矛盾的组合。
2. `AdvanceQuest`：接取时记录击杀基数；交付时先推进状态再发奖励，因此重复按键不能重复领取。
3. `QuestMeleeProgress / QuestRangedProgress`：累计击杀减去接取时基数，并限制显示上限，接取前的击杀不计入委托。
4. `UpdateQuestProgress`：两个目标都达标才变为可报告；Boss 死亡后变为最终报告。
5. `ConfirmQuestDialogue`：先翻页，最后一页才执行接取或交付；阅读提醒没有奖励。
6. `UpdateBoss`：追击 → 锁定方向并预警 → 出招 → 冷却。重斩检查扇形距离与方向，散射将同一方向旋转三次形成三发投射物。
7. `UpdateAppQuest / EnterMap`：发现 Boss 死亡后记录永久进度并清除战场攻击；进入巢穴时根据记录决定是否生成 Boss。

## 数据字典

| 数据 | 用途 |
|---|---|
| Quest.stage | 主线当前阶段，巢穴解锁由此推导，不另存重复的解锁开关 |
| Quest.startingMelee / startingRanged | 接取时的累计击杀基数 |
| Quest.bossDefeated | Boss 是否已击败；切图和复活后不再生成 |
| Player.meleeDefeated / rangedDefeated | 累计普通怪物分类击杀数 |
| App.dialoguePage | 当前对话页码，属于临时界面状态 |
| Enemy.attackVariant | 当前 Boss 攻击种类，0 重斩、1 散射 |
| Enemy.attackDirection / windup / cooldown | 锁定方向、预警剩余时间、攻击冷却 |

## Boss 当前数值与规则

| 项目 | 当前候选值 |
|---|---|
| 生命 / 追击速度 | 300 / 48 像素每秒 |
| 外观 / 身体碰撞框 | 约 64 像素 / 48×48 像素 |
| 初始探查范围 | 240 像素，需要视线无遮挡 |
| 重斩 | 90 像素范围、约 113 度扇形；预警 0.85 秒；30 伤害 |
| 散射 | 三发，预警 1 秒；每发 14 伤害；速度 160、射程 384 像素 |
| 出招后冷却 | 1.6 秒 |

近距离且上次不是重斩时选择重斩，否则散射；因此近身战会交替两种招式，远处主要使用散射。
预警开始后方向不再追着玩家旋转。身体接触不扣血；沿用玩家受伤无敌时间，三发不能同一瞬间叠加三次伤害。
Boss 复用按身体尺寸检查的寻路，不能挤进普通哥布林能通过的狭缝。进入安全区取消攻击并返回，但不恢复 Boss 生命。
头目和玩家同一帧死亡时，头目奖励与任务进度保留，仍显示死亡选择；奖励升级不会把死者自动复活。

## 亲自验收

1. 新游戏靠近主城村长按 E，读完三页，确认最后一页才接受；Esc 中途退出不会接取。F2 切换语言后对话和目标同步切换。
2. 接取前击杀一只，再接任务，确认不会计入任务。重新进入野外会重建怪物，可继续完成。
3. 接取后分别击败四只近战与两只远程，观察两项独立计数。死亡或往返主城不会清空进度。
4. 未交付时尝试野外右侧入口，仍锁定。回村完成两页交付后，金币增加 50、经验增加 60，入口解锁。
5. 再与村长交谈，不能再领这笔奖励。购买钢剑或符文法杖后亲自打开背包装备，再治疗。
6. 进入巢穴，观察大号 Boss、名字与血条。让它预警后绕到侧面，确认重斩能躲；远处避开三条射线，确认散射方向不会追着你改变。
7. 受伤后进入入口安全区，攻击取消、Boss 返回且生命不重置；治疗并继续挑战。死亡可选回主城或当前安全区，任务仍保留。
8. 击败 Boss，确认只领一次 150 金币、120 经验，出现返回村长提示。回村交付后再领 100 金币、60 经验并显示通关。
9. 通关后继续探索、再次与村长交谈、再次进入巢穴：不重复发任务奖励，不刷新 Boss。
10. 对话和通关按钮可用 Enter 或鼠标；关闭界面后松开攻击键再攻击，不能把按钮点击变成一记误攻击。
